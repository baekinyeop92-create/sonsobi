사용자가 붙여넣은 알림 원문:

$ARGUMENTS

CLAUDE.md의 "사용자가 알림 원문을 붙여넣으면" 절차를 그대로 따른다.
1. 각 원문을 CLAUDE.md 6번대로 가명 처리한다(이름 → 홍*동/홍길동, 계좌 → 123-45**-678, 카드 끝자리 → (1234), 날짜·시각 → 가상값, 금액·잔액·누적 → 임의 값, 지점명 → 삭제). 가맹점 상호와 문장 형식만 남긴다. 가명 처리 전 원문은 파일로 저장하지 않는다.
2. 원문마다 기대값(가맹점·금액·구분·항목)을 표로 제안하고 사용자 확인을 받는다.
3. 확인된 케이스를 test/fixtures/notifications.json에 추가한다. 기존 케이스 기대값은 바꾸지 않는다.
4. web/core/parse.js(필요하면 classify.js·categories.js)를 고치고 npm test 전부 통과시킨다.
5. 커밋·푸시(Pages 자동 배포). 과거 내역 중 분류가 바뀌는 유형이 있으면 한 줄로 알린다.
