폰 자동화 만들기

카드·은행 앱 알림이 오면 폰이 자동으로 내 구글 시트에 보내도록 설정합니다

← 앱으로
카드·은행 앱 알림→폰 자동화→내 구글 시트→순소비 앱

결제 내역은 내 구글 계정 밖으로 나가지 않습니다. 아래에 넣을 받기 주소와 WRITE_TOKEN은 설치를 끝낸 Claude Code가 마지막에 알려준 값을 씁니다. 이 값은 남에게 보여주지 마세요.

  1. 단축어 자동화 만들기

    • iOS 27 이상이 필요합니다. 단축어 앱 › 자동화 › + › 알림
    • 앱: 카드 앱 하나 선택 (현대카드, 신한 SOL페이, KB Pay …) · 필터: 메시지에 원 포함 · 즉시 실행 선택

  2. 보내기 동작 넣기

    • 동작 URL의 콘텐츠 가져오기: URL = 받기 주소, 방법 = POST, 요청 본문 = JSON
    • JSON 필드 4개: k = WRITE_TOKEN · app = 앱 이름(직접 입력) · title = 알림 › 제목 · body = 알림 › 본문

  3. 앱마다 반복

    카드·은행 앱마다 같은 자동화를 하나씩 만듭니다. 은행 앱을 넣어야 월세·적금 이체가 잡힙니다.

    메뉴 이름은 iOS 버전에 따라 조금 다를 수 있어요. ‘즉시 실행’이 없으면 알림이 올 때 한 번 눌러줘야 합니다.

  4. 확인

    카드로 한 번 결제해 보세요. 1분 안에 앱의 오늘 칸에 나타나면 성공입니다. 안 나타나면 자동화의 URL·JSON 필드를 다시 확인하세요.

  1. MacroDroid 매크로 만들기

    • MacroDroid 앱 설치 › 매크로 추가
    • 트리거: 알림 › 알림 수신 → 카드·은행 앱 선택, 텍스트에 원 포함

  2. 보내기 동작 넣기

    • 동작: HTTP 요청 → 방식 POST, URL = 받기 주소
    • 본문(콘텐츠)을 폼(키-값) 방식으로: k = WRITE_TOKEN · app = [not_app_name] · title = [not_title] · body = [notification]
    • k를 URL 쿼리에 넣지 마세요 — 반드시 본문에 넣습니다.

  3. 권한 설정

    MacroDroid에 알림 접근 권한을 켜고, 배터리 최적화에서 제외합니다.

  4. 확인

    카드로 한 번 결제해 보세요. 1분 안에 앱의 오늘 칸에 나타나면 성공입니다.

알림 문구는 카드사마다 달라서 가맹점을 못 읽는 경우가 있습니다. 그런 알림은 앱의 ‘확인할 것 › 인식 못 한 알림’에 원문 그대로 모입니다.
